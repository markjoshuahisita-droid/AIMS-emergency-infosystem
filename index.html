Emergency Procedures

Scan the QR code to instantly access emergency response guides for laboratory and engine room training.

Engine Room Fire

  1. Raise the fire alarm immediately.
  2. Inform the bridge or instructor.
  3. Stop fuel supply if safe.
  4. Close ventilation dampers.
  5. Use the correct fire extinguisher.
  6. Proceed to the designated muster station.

Flooding Response

  1. Report flooding immediately.
  2. Identify the source of water ingress.
  3. Close watertight doors.
  4. Start bilge pumping if instructed.
  5. Monitor compartment water level.
  6. Wait for further instructions.

Engine Room Blackout

  1. Stay calm and maintain communication.
  2. Check emergency lighting.
  3. Start the emergency generator if required.
  4. Restore essential systems safely.
  5. Record the incident after recovery.

Basic First Aid

  1. Ensure the scene is safe.
  2. Check responsiveness.
  3. Call for medical assistance.
  4. Control severe bleeding with pressure.
  5. Cool burns with clean running water.
  6. Do not move seriously injured persons unless necessary.
